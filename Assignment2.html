Today's topic is Block Level Element and Inline Elements

About Block Level Elements

Block-level elements HTML elements that always start on a new line and generally occupy the full available width of their parent container. They are used to structure and organize the content of a webpage. Even if the content is small, the next block-level element starts on a new line.

About Inline Elements

Inline elements are HTML elements that do not start on a new line. They occupy only the required space based on their content. Multiple inline elements can appear on the same line. They are mainly used to format text or add links within a paragraph.

Block level elements are

  • head tag: <head></head>
  • para tag :<p></p>
  • div tag : <div></div>

Sectioning Elements

Sectioning elements in HTML are used to divide a webpage into meaningful and organized sections. They help structure the content and make the webpage easier to understand and maintain. Each section is used to group related information based on its purpose. HTML5 introduced elements to add meaning to page structures.

They are

  • <header> Introductory content or navigation links for a section or page.
  • <footer> The footer for a section or page.
  • <article>Self-contained, independent content like a blog post or news story.
