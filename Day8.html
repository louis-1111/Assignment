Task 6 – Box Model Formula

Box Model Calculation

                    Total Width =Content Width + Left Padding + Right Padding
                                +
                    Left Border + Right Border
                                +
                    Left Margin + Right Margin


Content

Content: Calculated directly from your set width and height values.


Padding

2. Calculated by adding left + right padding for width, and top + bottom padding for height.


Border

Calculated by adding left + right border thickness for width, and top + bottom thickness for height.


Margin

Calculated by adding left + right margin for outer width, and top + bottom margin for outer height.
